# GeoBaro（国土地理院・気象庁 標高＆気圧換算ビューア）

国土地理院の標高・住所・地図タイルデータと気象庁の過去気象観測データ（過去の気象データ検索）を連携させ、現在地の標高に応じた現地気圧換算および指定日の気象推移を表示するGUIアプリケーションです。

---

## 1. 主な機能と特徴

1. **現在地の特定と精密な標高取得（国土地理院API連携）**
   * 日本国内の住所表記（例: `東京都千代田区千代田1-1`）または緯度経度（カンマ区切り `35.6814, 139.7670` や空白区切り `35.6814 139.7670`）を入力可能。
   * 国土地理院の住所検索APIで正規化住所と座標を解決し、数値標高モデル（DEM）から精密な標高（メートル単位）を取得します（JSON内の `\uXXXX` エスケープ文字列もUTF-8へ正常デコード）。

2. **現在地周辺の地図・地形図プレビュー（拡大縮小・位置微修正・スケールバー・レイヤー切替）**
   * 国土地理院の地図タイルを周囲タイルから合成（高DPIスケーリング対応 `320×320`、メモリ内LRUタイルキャッシュ付き）し、中央の精密クロスヘアと右下の距離スケールバーにより現在地と距離感を視覚確認できます。
   * 地図種別を「標準地図」「淡色地図」「色別標高図」から切り替え可能。
   * **ズーム（Z10〜Z18）**：`−`/`＋`ボタンまたは地図上でのマウスホイールで拡大・縮小可能（色別標高図で Z16〜Z18 を選択時は Z15 タイルから自動拡大表示）。
   * **地図上での現在地微修正（方式A）**：地図を左ドラッグ（パン）またはダブルクリックすることで現在地を建物・区画単位で微調整し、標高・換算気圧を自動更新します。微修正時は入力欄を微修正後の緯度経度に連動させつつ元の住所表記も保持（`(位置微修正済み)`表示）し、`元位置へ` ボタンでいつでも元の検索位置へ戻せます。

3. **現在地プリセット（地点登録）機能**
   * よく使う地点を名前付きで登録・選択呼び出し・削除可能。微修正済みの緯度経度・元住所表記・地上高（m）・地図ズーム倍率もまとめて保存されます（設定ファイル `presets.dat` は実行ファイルと同階層またはユーザーデータディレクトリへ保存）。

4. **最寄り気象官署の自動探索とデータ取得（気象庁Web連携）**
   * 全国の気圧観測官署（気象台・特別地域気象観測所など154地点）のマスターを内蔵。
   * 大圏距離計算（球面三角法）に現在地地盤標高と官署標高の差（標高差 $50\text{ m}$ あたり水平距離 $1\text{ km}$ 相当の重み）を加味した評価スコアにより、平野部で極端な山岳官署（富士山頂等）が選ばれることによる外挿誤差を防ぎつつ最適な最寄り気圧観測所を自動選定。
   * 対象日ピッカーに加え、`◀`（前日）・`▶`（翌日）・`今日` ボタンを備え、日付変更時は現在地を保ったまま気象データのみを高速に自動再照会します。また、通信中に「中止」ボタンでキャンセルも可能です。
   * 指定日の1時間ごと（過去日は1時〜24時、当日は0時〜最新時刻）の観測値（気温、湿度、観測所現地気圧、海面気圧、天候）を取得します。

5. **測高公式による現在地標高＋地上高への気圧換算（リアルタイム再計算対応）**
   * 地盤標高（DEM）に加え、**地上高（0.0〜2000.0 m）**を指定可能。建物の高層階や展望台などにおける高度 $h_{\text{target}} = h_{\text{ground}} + h_{\text{agl}}$（換算標高）での現地気圧を計算できます。
   * 観測所の地上気温 $T_{\text{obs}}$ と観測所標高 $h_{\text{stn}}$ から海面基準気温 $T_0 = T_{\text{obs}} + 0.0065 \cdot h_{\text{stn}}$ を算出し、実測値である**観測所現地気圧 $P_{\text{stn}}$** と官署標高 $h_{\text{stn}}$ から国際標準大気（ICAO）測高公式を用いて現在地換算気圧を直接算出（海面更正の往復による微小バイアスを排除）：
     $$P_{\text{target}} = P_{\text{stn}} \cdot \left( \frac{1 - \frac{0.0065 \cdot h_{\text{target}}}{T_0 + 273.15}}{1 - \frac{0.0065 \cdot h_{\text{stn}}}{T_0 + 273.15}} \right)^{5.257}$$
   * 現地気圧が欠測で海面更正気圧 $P_0$ のみ有効な場合は、$P_0$ からフォールバック換算します。
   * 海面気圧との高度差による気圧差（$P_{\text{target}} - P_0$）および対象日の換算気圧サマリー（最新・最高・最低）も同時に表示。すでにデータ取得済みの状態で地上高スピンコントロールを変更（または Enter 確定）すると、再通信なしで換算気圧・サマリー・一覧表が即座に再計算されます。

6. **24時間推移リスト ＆ クリップボードコピー・CSVエクスポート**
   * 指定日の推移を一覧テーブル表示（交互行配色・欠測行グレー表示・当日最新行ハイライト付き）。右クリックメニューのほか、`Ctrl+C` での行コピーやダブルクリックでの換算気圧コピー、サマリー欄の座標コピーに対応しています。
   * 結果をUTF-8（BOM付き・RFC 4180準拠クォート処理付き）CSVファイルとして保存可能（Excel等ですぐ開け、ヘッダ行に地盤標高・地上高・換算標高を記録します）。

7. **単一EXEポータブル配布（外部DLL不要）**
   * MinGW g++ 13.2.0 および wxWidgets 3.2.6 を**完全静的リンク（`-static`）**。
   * 通信にはWindows標準の `WinINet`（OS組み込み）を使用しているため、外部DLL（libcurl, OpenSSL, wxWidgets DLL等）を一切必要とせず、**`GeoBaro.exe` 単体で配布・即座に実行可能**です（Windows 10/11 UCRT環境）。

## 2. ビルド方法

1. wxWidgets 3.2.x のソースを取得し、`build/msw` 配下で MinGW 用の静的ライブラリをビルドします：
   ```bat
   mingw32-make -f makefile.gcc -j4 BUILD=release SHARED=0 UNICODE=1
   ```
2. 本リポジトリのルートで `WX_DIR` を指定して `mingw32-make` を実行します：
   ```bat
   mingw32-make WX_DIR=C:/path/to/wxWidgets-3.2.6
   ```
   ロジック検証用CLIをビルドする場合：
   ```bat
   mingw32-make test_cli.exe
   ```

## 3. 実行ファイル・ソースコード構成

* `GeoBaro.exe`: GUIメインアプリケーション（静的リンク単一EXE）
* `test_cli.exe`: コアロジック検証用CLIツール
* `src/main.cpp`: wxWidgets アプリケーションエントリポイント
* `src/main_frame.h` / `src/main_frame.cpp`: GUIメインウィンドウ（プリセット管理、入力フォーム、サマリー、レイヤー・ズーム切替、24時間推移リスト、CSV出力、常駐ワーカースレッド管理）
* `src/map_panel.h` / `src/map_panel.cpp`: 国土地理院タイル合成描画・拡大補間・左ドラッグ/ダブルクリック位置微修正パネル
* `src/gsi_service.h` / `src/gsi_service.cpp`: 国土地理院 住所検索API・標高API・Webメルカトル座標変換・LRUキャッシュ付きタイル取得ロジック
* `src/preset_store.h` / `src/preset_store.cpp`: 現在地プリセットのシリアライズ・管理ロジック
* `src/resource.rc`: Windows アプリケーションアイコンおよび Common Controls v6 / PerMonitorV2 DPI Awareness マニフェスト定義
* `icons/app_icon.ico`: アプリケーション用アイコンファイル（アネロイド気圧計・コンパス合成デザイン）
* `src/jma_service.h` / `src/jma_service.cpp`: 気象庁過去データ検索HTMLパーサー・最寄り地点探索・測高気圧換算
* `src/jma_stations.h` / `src/jma_stations.cpp`: 全154地点の気象官署マスターテーブル
* `jma_stations.json` / `generate_stations_cpp.py`: 気象官署マスターデータ（JSON）および `src/jma_stations.cpp` 再生成用スクリプト
* `src/http_transport.h` / `src/http_transport.cpp`: WinINet によるHTTPS通信ラッパー（タイムアウト・HTTPステータス検証付き）
* `Makefile`: MinGW g++ 用の静的リンクビルド構成（画像コーデックは PNG のみリンク、`-fmacro-prefix-map` 指定済み）
* `.gitignore`: ユーザー設定ファイル（`presets.dat`）・ビルド成果物（`*.exe`, `*.o` 等）除外設定
* `LICENSE`: 本ソフトウェアおよび独自アイコンの MIT ライセンス全文
* `THIRD_PARTY_NOTICES.md`: 静的リンクしているサードパーティライブラリ・ランタイムのライセンス・著作権表示
* `REGENERATION_PROMPT.md`: 将来のAPI変更時にエージェントへ同機能アプリを再生成させるためのプロンプト仕様書
