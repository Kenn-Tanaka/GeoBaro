# GeoBaro（国土地理院・気象庁 標高＆気圧換算ビューア）

国土地理院の標高・住所・地図タイルデータと気象庁の過去気象観測データ（過去の気象データ検索）を連携させ、現在地の標高に応じた現地気圧換算および指定日の気象推移を表示するGUIアプリケーションです。

バージョン番号は `年.月.日.連番` です。日付は日本標準時で、当日の初回リリースは連番を `1` とし、同日のリリースごとに増やします。番号は「ヘルプ」→「バージョン情報」、または `GeoBaro.exe` のプロパティの「詳細」で確認できます。リリース時の番号は `src/version.h` で管理します。

## 1. 主な機能と特徴

1. **現在地の特定と精密な標高取得（国土地理院API連携）**
   * 日本国内の住所表記（例: `東京都千代田区千代田1-1`）または緯度経度（カンマ区切り `35.6814, 139.7670` や空白区切り `35.6814 139.7670`）を入力可能。
   * 国土地理院の住所検索APIで正規化住所と座標を解決し、数値標高モデル（DEM）から精密な標高（メートル単位）を取得します（JSON内の `\uXXXX` エスケープ文字列もUTF-8へ正常デコード）。

2. **現在地周辺の地図・地形図プレビュー（拡大縮小・位置微修正・スケールバー・レイヤー切替）**
   * 国土地理院の地図タイルを周囲タイルから合成（高DPIスケーリング対応 `320×320`、メモリ内LRUタイルキャッシュ付き）し、中央の精密クロスヘアと右下の距離スケールバーにより現在地と距離感を視覚確認できます。
   * 地図種別を「標準地図」「淡色地図」「色別標高図」から切り替え可能。
   * **ズーム（Z10〜Z18）**：`−`/`＋`ボタンまたは地図上でのマウスホイールで拡大・縮小可能（色別標高図で Z16〜Z18 を選択時は Z15 タイルから自動拡大表示）。
   * **地図上での現在地微修正（方式A）**：地図を左ドラッグ（パン）またはダブルクリックすることで現在地を建物・区画単位で微調整し、標高・換算気圧を自動更新します。微修正時は入力欄を微修正後の緯度経度に連動させつつ元の住所表記も保持（`(位置微修正済み)`表示）し、`元位置へ` ボタンでいつでも元の検索位置へ戻せます。

3. **現在地プリセット（地点登録）機能**
   * よく使う地点を名前付きで登録・選択呼び出し・削除可能。微修正済みの緯度経度・元住所表記・地上高（m）・地図ズーム倍率もまとめて保存されます（設定ファイル `presets.dat` は実行ファイルと同階層またはユーザーデータディレクトリへ保存）。

4. **最寄り気象官署の自動探索とデータ取得（気象庁Web連携）**
   * 全国の気圧観測官署（つくば（館野）を含む155地点）のマスターを内蔵。
   * 1961年以降は対象日の正午の位置で主官署を選び、各時刻の換算には観測時点の地点情報を使います。東京の2014年12月2日の移転は9時40分（JST）で切り替えます。官署標高が不明なときは、官署選定の標高差と単点換算の基準気温に気圧計高度を近似値として使います。気温または両方の高度が不明な場合は、単点換算の海面基準気温を15 ℃とします。1960年以前は現在位置から距離順に最大3官署を試し、有効な時別気圧のある官署の海面気圧から換算します。
   * 大圏距離計算（球面三角法）に現在地地盤標高と官署標高の差（標高差 $50\text{ m}$ あたり水平距離 $1\text{ km}$ 相当の重み）を加味した評価スコアにより、平野部で極端な山岳官署（富士山頂等）が選ばれることによる外挿誤差を防ぎつつ最適な最寄り気圧観測所を自動選定。
   * 対象日ピッカーに加え、`◀`（前日）・`▶`（翌日）・`今日` ボタンを備え、過去データを取得できなかった場合は、気象庁の公開日を基準に直近9日以内のAMeDAS速報を照会します。日付変更時は現在地の気象データのみを再照会します。通信中に「中止」を押すと、照会前の入力に戻ります。
   * 指定日の1時間ごと（過去日は1時〜24時、当日は0時〜最新時刻）の観測値（気温、湿度、観測所現地気圧、海面気圧、天候）を取得します。

5. **測高公式 ＆ 複数観測所の空間補間による現在地現地気圧算出（リアルタイム再計算対応）**
   * 地盤標高（DEM）に加え、**地上高（−2000.0〜2000.0 m）**を指定できます。地下室なら、地盤から5 m下の地点に `-5.0` と入力します。地盤標高と地上高を足した換算標高で気圧を推定します。室内の換気や加圧による気圧差は計算に含まれません。
   * 推移リストには最寄り官署の観測値（天候・気温・湿度・観測所気圧・海面気圧）を維持したうえで、`★ 現在地換算気圧` の算出には現在地周辺（半径 $100\text{ km}$ 以内・近い順最大 6 地点）の海面気圧・気温を用いた**空間補間パイプライン**を適用します：
     * **Step 1（局所座標・海面換算気温）**: 官署標高が記録されている観測時刻を対象とし、目標地点原点の局所直交座標 $(x_i, y_i)$ [km] と各観測所の海面換算気温 $T_{0,i} = T_i + 0.0065 \cdot z_i$ を算出。過去日の24時は翌日0時の地点情報を使います。
     * **Step 2（空間補間）**: 重み $w_i = 1 / (d_i + 1.0)^2$ により、有効観測所 4 点以上かつ非共線・外挿範囲内では**重み付き最小二乗平面近似（PlaneFit）**で海面気圧 $\hat{P}_0$ と気圧傾度 $(a, b)$ を推定（3 点以下・共線縮退・外挿異常時は **IDW**、1 点時は **SingleNearest** へ自動フォールバック）。海面換算気温 $\hat{T}_0$ は常に IDW で平滑化します。
     * **Step 3（測高公式換算）**: $\hat{T}_H = \hat{T}_0 - 0.0065 \cdot H$、$P_{\text{local}} = \hat{P}_0 \cdot \left( \frac{\hat{T}_H + 273.15}{\hat{T}_H + 273.15 + 0.0065 \cdot H} \right)^{5.257}$。
   * 補間補正量・使用手法・使用観測所・気圧傾度はサマリー欄の `空間補間補正:` 行およびツールチップで確認できます（最寄り官署が至近で現地気圧のみ持つ富士山頂等の過去日照会時は単点現地気圧直接換算を優先）。すでにデータ取得済みの状態で地上高スピンコントロールを変更（または Enter 確定）すると、再通信なしで換算気圧・サマリー・一覧表が即座に再計算されます。

6. **24時間推移リスト ＆ クリップボードコピー・CSVエクスポート**
   * 指定日の推移を一覧テーブル表示（交互行配色・欠測行グレー表示・当日最新行ハイライト付き）。右クリックメニューのほか、`Ctrl+C` での行コピーやダブルクリックでの換算気圧コピー、サマリー欄の座標コピーに対応しています。
   * 結果をUTF-8（BOM付き・RFC 4180準拠クォート処理付き）CSVファイルとして保存可能（Excel等ですぐ開け、ヘッダ行に地盤標高・地上高・換算標高を記録します）。

7. **単一EXEポータブル配布（外部DLL不要）**
   * MinGW g++ 13.2.0 および wxWidgets 3.2.6 を**完全静的リンク（`-static`）**。
   * 通信にはWindows標準の `WinINet`（OS組み込み）を使用しているため、外部DLL（libcurl, OpenSSL, wxWidgets DLL等）を一切必要とせず、**`GeoBaro.exe` 単体で配布・即座に実行可能**です（Windows 10/11 UCRT環境）。

8. **アプリ内ヘルプ**
   * 「ヘルプ」メニューまたは `F1` で、使い方・結果の見方・計算の仕組み・気圧の不確かさを参照できます。説明はEXEに内蔵され、オフラインでも読めます。ヘルプを開いたままメイン画面を操作でき、`Esc` で閉じられます。

## 2. ビルド方法

1. wxWidgets 3.2.x のソースを取得し、`build/msw` 配下で MinGW 用の静的ライブラリをビルドします：
   ```bat
   mingw32-make -f makefile.gcc -j4 BUILD=release SHARED=0 UNICODE=1
   ```
2. 本リポジトリのルートで `WX_DIR` を指定して `mingw32-make` を実行します：
   ```bat
   mingw32-make WX_DIR=C:/path/to/wxWidgets-3.2.6
   ```
   ロジック検証用CLIをビルドする場合：
   ```bat
   mingw32-make test_cli.exe
   ```

wxWidgetsをCMakeとNinjaでビルドする場合は、MinGWがPATHにある状態で次の手順を使えます。以下は64ビット版の例です。

```bat
set WX_DIR=C:/src/wxWidgets-3.2.6
set WX_BUILD=C:/build/wx326
cmake -S %WX_DIR% -B %WX_BUILD% -G Ninja -DCMAKE_BUILD_TYPE=Release -DwxBUILD_SHARED=OFF -DwxUSE_LIBPNG=builtin -DwxUSE_ZLIB=builtin -DwxUSE_REGEX=builtin -DwxUSE_EXPAT=builtin -DwxUSE_LIBJPEG=OFF -DwxUSE_LIBTIFF=OFF -DwxUSE_WEBVIEW=OFF -DwxUSE_WEBREQUEST=OFF -DwxUSE_STC=OFF "-DCMAKE_C_FLAGS=-ffile-prefix-map=%WX_DIR%=wxWidgets" "-DCMAKE_CXX_FLAGS=-ffile-prefix-map=%WX_DIR%=wxWidgets"
cmake --build %WX_BUILD% --parallel --target wxcore wxbase wxnet wxadv wxexpat
mingw32-make WX_DIR=%WX_DIR% WX_LIB_ROOT=%WX_BUILD%/lib/gcc_x64_lib
```

固定データによる回帰テストと実通信テストは個別に実行できます。

```bat
mingw32-make test_offline.exe test_cli.exe
test_offline.exe
test_cli.exe
```

履歴を更新する際は気象庁の `smaster.index` ZIPを取得し、`python generate_stations_cpp.py --import-history smaster.index.zip` を実行します。通常の再生成は `python generate_stations_cpp.py` で行えます。地上気象観測の地点情報履歴を加工して作成しています。[気象庁の配布ページ](https://www.data.jma.go.jp/stats/mdrr/man/kansoku_gaiyou.html)

## 3. 実行ファイル・ソースコード構成

* `GeoBaro.exe`: GUIメインアプリケーション（静的リンク単一EXE）
* `test_cli.exe`: コアロジック検証用CLIツール
* `src/main.cpp`: wxWidgets アプリケーションエントリポイント
* `src/main_frame.h` / `src/main_frame.cpp`: GUIメインウィンドウ（プリセット管理、入力フォーム、サマリー、レイヤー・ズーム切替、24時間推移リスト、CSV出力、常駐ワーカースレッド管理）
* `src/map_panel.h` / `src/map_panel.cpp`: 国土地理院タイル合成描画・拡大補間・左ドラッグ/ダブルクリック位置微修正パネル
* `src/gsi_service.h` / `src/gsi_service.cpp`: 国土地理院 住所検索API・標高API・Webメルカトル座標変換・LRUキャッシュ付きタイル取得ロジック
* `src/preset_store.h` / `src/preset_store.cpp`: 現在地プリセットのシリアライズ・管理ロジック
* `src/resource.rc`: Windows アプリケーションアイコンおよび Common Controls v6 / PerMonitorV2 DPI Awareness マニフェスト定義
* `icons/GeoBaro-v2.ico`: 日本列島とアネロイド気圧計のアイコン（16〜256 pxの7サイズ）。
* `src/jma_service.h` / `src/jma_service.cpp`: 気象庁過去データ検索HTMLパーサー・最寄り地点探索・周辺観測所バッチ取得・測高気圧換算
* `src/spatial_pressure.h` / `src/spatial_pressure.cpp`: 複数観測所の空間補間（重み付き最小二乗平面近似・IDW・測高換算）による局所気圧算出モジュール
* `src/jma_stations.h` / `src/jma_stations.cpp`: 全155地点の気象官署マスターテーブル
* `jma_stations.json` / `generate_stations_cpp.py`: 気象官署マスターデータ（JSON）および `src/jma_stations.cpp` 再生成用スクリプト
* `src/http_transport.h` / `src/http_transport.cpp`: WinINet によるHTTPS通信ラッパー（タイムアウト・HTTPステータス検証付き）
* `Makefile`: MinGW g++ 用の静的リンクビルド構成（画像コーデックは PNG のみリンク、`-fmacro-prefix-map` 指定済み）
* `.gitignore`: ユーザー設定（`presets.dat`）、ビルド成果物、ローカルの退避用フォルダ（`_archive/`）をGit管理から除外。
* `LICENSE`: 本ソフトウェアおよび独自アイコンの MIT ライセンス全文
* `THIRD_PARTY_NOTICES.md`: 静的リンクしているサードパーティライブラリ・ランタイムのライセンス・著作権表示
* `REGENERATION_PROMPT.md`: 将来のAPI変更時にエージェントへ同機能アプリを再生成させるためのプロンプト仕様書
